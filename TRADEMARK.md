## What this means in practice

- You may build, run, modify and redistribute the code under either of the two code licences,
  including for commercial purposes, exactly as those licences say.
- A fork or other derivative work must not use the name "Namir" or the brand assets to identify
  itself. Replace them with your own name and artwork before distributing your build.
- You may state factually that your work is derived from Namir. Using the name to describe where
  your code came from is not the same as using it as the name of your product.
- Screenshots and unmodified copies of the mark used to refer to Namir itself — in a review, an
  article, a plugin list, or documentation about Namir — are fine and need no permission.

If you want to use the name or the assets in a way this document does not allow, ask. Open an issue
on the repository's issue tracker at <https://github.com/ErwanLegrand/namir/issues> describing what
you want to use and how; permission is granted in writing or not at all.
